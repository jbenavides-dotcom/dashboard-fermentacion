# Dashboard Fermentación de Café — La Palma y el Tucán

Dashboard de monitoreo de los 5 protocolos de fermentación de Katherine Rodríguez (LPX-500, BIW-200, NO-120, CSP-48, BNX-100).

**Live:** https://jbenavides-dotcom.github.io/dashboard-fermentacion/
**Stack:** HTML + CSS + JS vanilla + Chart.js
**Variables monitoreadas:** °Brix, pH, Temperatura
**Hardware:** ESP32 + 2× pH PH-4502C + 2× DS18B20 → webhook n8n

Forma parte del [Centro de Control Finca](https://jbenavides-dotcom.github.io/finca-dashboard/).
